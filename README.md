# React Calculator App - Test Driven Development (TDD)

## Introduction
This Project is a simple calculator application built using React, following the principles od Test-driven Development. The calculator performs three core functions: addtion, subtraction and multiplication.

## Objectives
1. Create a React-based calculator application.
2. Write tests for calculator functionalities before implementing them.
3. Implement calculator functionalities to pass the written tests.


### 1. Setup
- Initialize a new React project using `Create React App`.
- Install necessary testing libraries (e.g., Jest, React Testing Library).

## Getting Started

### Prerequisites
- Node.js and npm installed on your system.

### Installation
```bash
# Clone the repository
git clone https://github.com/mounikagollu1996/tdd-calculator.git

git checkout develop

# Navigate to the project directory
cd tdd-calculator
cd react-calculator-tdd

# Install dependencies
npm install
```

### Running the Application
```bash
# Start the development server
npm start
```
The app will be accessible at `http://localhost:3000`.

### Running Tests
```bash
# Run the test suite
npm test
```
